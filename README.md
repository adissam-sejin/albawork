# 알바 주간정산

알바생이 출근·퇴근·한 일을 기록하고, 관리자가 월~일 단위로 정산해 실제 입금액을 남기는 모바일 웹앱입니다.
데이터는 구글 시트 한 곳에 저장되고, 연도별 탭으로 나뉩니다. **Apps Script는 쓰지 않습니다.**

```
albawork/
├─ index.html      ← 화면 (알바생 + 관리자)
├─ api/
│  └─ index.js     ← 서버 (구글 시트 읽고 쓰기)
└─ README.md
```

---

## 한 번만 하는 준비 (약 15분)

앱이 구글 시트에 직접 쓰려면 "서비스 계정"이라는 로봇 계정의 열쇠(JSON 파일)가 필요합니다. 처음 한 번만 만들면 됩니다.

### 1. 구글 시트 만들기
1. 구글 드라이브에서 빈 스프레드시트를 새로 만듭니다. 이름은 자유 (예: 알바 주간정산 데이터)
2. 주소창의 주소 전체를 복사해 둡니다. → 나중에 `SHEET_ID`에 넣습니다.
3. 탭은 만들지 않아도 됩니다. 앱이 알아서 만듭니다.

### 2. 구글 클라우드에서 열쇠 만들기
1. https://console.cloud.google.com 접속 (시트를 만든 구글 계정으로)
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `albawork` → 만들기
3. 검색창에 **Google Sheets API** 검색 → **사용(Enable)** 클릭
4. 왼쪽 메뉴 **IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기**
   - 이름: `albawork` → 만들고 계속하기 → 역할은 선택하지 않고 **완료**
5. 만들어진 서비스 계정을 클릭 → **키** 탭 → **키 추가 → 새 키 만들기 → JSON** → 파일이 다운로드됩니다.
6. 다운로드된 JSON 파일을 메모장으로 열어두세요. `"client_email"` 옆의 주소(….iam.gserviceaccount.com)가 로봇 계정 이메일입니다.

> JSON 파일은 열쇠라서 다른 사람에게 보내거나 GitHub에 올리지 마세요.

### 3. 시트를 로봇 계정에 공유
1. 1번에서 만든 구글 시트 → 오른쪽 위 **공유**
2. `client_email` 주소를 붙여넣고 **편집자**로 → 알림 체크 해제 → 공유

### 4. GitHub에 올리기
1. GitHub에서 **새 저장소**를 만듭니다. (예: `ovdesign_albawork2`)
   - 예전 버전 저장소에 덮어쓰면 옛날 파일이 섞여 오류가 날 수 있어서 새 저장소를 권합니다.
2. **Add file → Upload files**에 `index.html`, `README.md`, `api` 폴더를 통째로 끌어다 놓고 Commit
3. 저장소에 `api/index.js`가 폴더째로 보이면 성공

### 5. Vercel에 배포
1. https://vercel.com → **Add New → Project** → 방금 만든 저장소 **Import**
2. Framework Preset은 **Other** 그대로, 다른 설정은 건드리지 않습니다.
3. **Environment Variables**에 아래 3개를 넣습니다.

| 이름 | 값 |
|---|---|
| `GOOGLE_CREDENTIALS` | JSON 파일 내용 **전체** (`{` 부터 `}` 까지 통째로 복사) |
| `SHEET_ID` | 구글 시트 주소 전체 (주소를 그대로 넣어도 됩니다) |
| `ADMIN_PASSWORD` | `adi2026` |

4. **Deploy**

> 이미 배포한 뒤에 환경변수를 넣거나 고쳤다면 **Deployments → 맨 위 배포 … → Redeploy**를 해야 적용됩니다.

### 6. 연결 점검
배포 주소 뒤에 `/api`를 붙여 열어보세요. (예: `https://ovdesign-albawork2.vercel.app/api`)

5칸이 모두 **통과**면 끝입니다. 이때 시트에 `알바생` 탭이 생깁니다.
빨간 칸이 있으면 적힌 안내대로 고치고 Redeploy 후 새로고침하세요.

## 사용법

### 관리자
1. 첫 화면에서 아이디 `admin`, 비밀번호 `adi2026`
2. **알바생 관리 → 알바생 추가**: 이름, 아이디, 비밀번호, 시급(기본 12,000원) → 알려줄 아이디·비밀번호가 화면에 뜹니다.
   - 알바생 계정은 **관리자만 만들 수 있어요.** 알바생이 스스로 가입하는 화면은 없습니다.
3. **주간 정산**: 주를 넘겨가며 알바생별 근무일수, 시간, 계산 금액, 상태를 봅니다.
   - 상태: 진행 중 → (일요일 밤 10시 지나면) 정산 대기 → 입금 완료
4. 알바생을 누르면 그 주 근무 기록과 업무 내용이 나오고, 아래에서 **실제 입금액**을 적어 저장합니다.
   - `+5천`, `+1만` 버튼으로 더 보내준 금액을 빠르게 올릴 수 있고, 차액과 메모가 시트에 남습니다.
5. 퇴근을 안 찍었거나 시간이 틀리면 기록의 **수정**에서 고칩니다. 빠진 날은 **기록 추가**.
   - 알바생이 직접 넣거나 고친 기록에는 `알바생 입력`, `알바생 수정` 표시가 붙어요.
   - 관리자는 입금이 끝난 주도 고칠 수 있어요. 고친 뒤 계산 금액이 달라지면 입금 기록 칸에 안내가 뜹니다.
6. 알바생을 **중지**하면 로그인은 막히고 지난 기록은 남습니다. 비밀번호를 잊으면 새로 정해주세요.
7. 오른쪽 위 **시트** 버튼으로 구글 시트를 바로 엽니다.

### 알바생
1. 받은 아이디·비밀번호로 로그인 (한 번 로그인하면 90일 유지)
2. **출근하기** → 일하는 중에 "오늘 한 일"을 적고 → **퇴근하기** (한 일을 적어야 퇴근됩니다)
3. 아래 주간 출근카드에서 이번 주 기록, 합계, 정산일, 입금 완료 금액을 봅니다.
4. 출퇴근을 못 찍은 날은 그 날짜 칸의 **기록 추가**나 아래 **근무 기록 추가**로 넣습니다.
5. 입금 기록이 저장되기 전까지는 알바생이 기록의 시간·내용을 **수정**하거나 삭제할 수 있어요. 입금이 끝난 주는 잠깁니다.

**알바생이 직접 넣을 때 규칙**
- 이번 주와 지난주 기록만 넣을 수 있어요. 그보다 오래된 기록은 관리자가 넣습니다.
- 아직 지나지 않은 시간은 넣을 수 없어요.
- 퇴근 칸을 비워두는 건 오늘·어제 출근 기록만 가능해요. (나중에 퇴근 버튼으로 마무리)
- 같은 사람의 기록끼리 시간이 겹치면 저장되지 않아요.
- 한 번에 16시간을 넘으면 오전/오후 실수로 보고 막아요.
- 퇴근 시간을 넣을 때는 그날 한 일도 적어야 해요.

> 휴대폰 홈 화면에 추가해두면 앱처럼 쓸 수 있습니다. (크롬 메뉴 → 홈 화면에 추가)

## 구글 시트 구조

| 탭 | 내용 |
|---|---|
| `알바생` | 아이디, 이름, 시급, 상태, 연락처, 등록일, 비밀번호(암호화) |
| `2026 근무` | 날짜, 요일, 이름, 아이디, 출근, 퇴근, 근무시간, 근무(분), 시급, 금액, 업무내용, 수정일시, 기록ID, 기록방법 |
| `2026 정산` | 주 시작(월), 주 끝(일), 이름, 아이디, 근무시간, 근무(분), 계산금액, 입금액, 차액, 입금일, 메모, 기록일시 |

- 해가 바뀌면 `2027 근무`, `2027 정산` 탭이 자동으로 생깁니다.
- 근무 기록은 **출근한 날짜**의 연도 탭에, 정산은 **주 끝(일요일)** 연도 탭에 들어갑니다.
- 기록방법: `출퇴근 버튼`, `알바생 입력`, `알바생 수정`, `관리자 입력`, `관리자 수정` 중 하나가 남습니다. (시간을 바꿨을 때만 수정으로 바뀌어요)
- 시급은 출근할 때의 시급이 기록마다 저장됩니다. 시급을 올려도 지난 기록 금액은 바뀌지 않습니다.
- 금액 = 근무(분) × 시급 ÷ 60 (원 단위 반올림), 주 합계는 기록별 금액의 합입니다.

**시트에서 하지 말아야 할 것**
- 탭 이름 바꾸기, 열 순서 바꾸기, 1행 제목 지우기
- 출근·퇴근 시간을 시트에서 직접 고치기 → 근무시간과 금액이 따라 바뀌지 않습니다. 시간 수정은 앱에서 해주세요.
- 필터·정렬·색칠·열 오른쪽에 메모 추가는 괜찮습니다.

## 자주 나는 오류

| 화면에 뜨는 말 | 고치는 법 |
|---|---|
| 환경변수 ○○가 비어 있어요 | Vercel 환경변수 이름 철자 확인 → Redeploy |
| GOOGLE_CREDENTIALS 내용이 올바른 JSON이 아니에요 | JSON 파일을 메모장으로 열어 전체 선택(Ctrl+A) 복사 후 다시 붙여넣기 |
| 구글 로그인에 실패했어요 | 서비스 계정 키가 삭제됐을 수 있어요. 새 키(JSON)를 만들어 다시 넣기 |
| Google Sheets API가 꺼져 있어요 | 구글 클라우드에서 Sheets API **사용** 클릭 (켠 뒤 1~2분 기다리기) |
| 구글 시트에 접근 권한이 없어요 | 시트 공유에 로봇 계정 이메일을 **편집자**로 추가 |
| 구글 시트를 찾을 수 없어요 | `SHEET_ID`에 넣은 시트 주소 확인 |
| 서비스 계정 키 만들기가 막혀 있음 | 회사·학교 구글 계정이면 막혀 있을 수 있어요. 개인 gmail 계정으로 프로젝트를 만드세요 |
